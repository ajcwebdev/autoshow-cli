# Harborlight comic source bundle

This original four-panel adaptation of the [Harborlight treatment](../harborlight-camp-treatment.md) uses episode 2, scene 1, Papa Bear and Mira, and the Harborlight Camp location. Papa Bear is an adult human guide with a nickname. Both characters are adults. The script and simple cast drawings were authored for this repository and use the [Harborlight MIT license](../../harborlight-LICENSE.txt).

`papa-bear.svg` and `mira.svg` are original front-view design drawings, with matching PNG exports. They establish faces and clothing but are not generated three-view turnarounds or evidence of hosted image quality. `harborlight-camp.svg` and its PNG export show the matching empty location: circular stone fire ring, timber bench behind it, and a path between two pine trees. They contain no character likenesses. The parent directory's tent/telescope style seed remains a separate treatment/style input and is not this scene's location reference.

Run `bun --no-env-file src/tools/prepare-harborlight-comic.ts` from the repository root to copy these inputs into a fresh isolated `runtime/examples/harborlight-comic` workspace and create valid character/location catalogs. The helper registers the original cast drawings as `legacy-import` with `model: null`, and the supplied campsite as `existing-canonical-art` with its real checksum, rather than claiming provider generation. It refuses an existing destination. It creates no voice registrations, generated scene, panel images, audio, or slideshow.

Follow the [comic walkthrough](../../../../docs/commands/05-visuals/comic/00-comic-overview.md#walkthrough-harborlight) for local preparation, hosted-stage prerequisites, cumulative estimates, image generation, audio, and the slideshow. The first valid generated image for each panel becomes its selection automatically, so no separate publication step is needed; replacing a panel later is an explicit `comic review --run <image-run-id> --use` choice. All edits and generated outputs belong in the copied runtime workspace. Leave this source bundle unchanged.
