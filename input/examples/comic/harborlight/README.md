# Harborlight comic source bundle

This original four-panel adaptation of the [Harborlight treatment](../harborlight-camp-treatment.md) uses episode 2, scene 1, Papa Bear and Mira, and the Harborlight Camp location. Papa Bear is an adult human guide with a nickname. Both characters are adults. The script, review exercise, and simple cast drawings were authored for this repository and use the [Harborlight MIT license](../../harborlight-LICENSE.txt).

`papa-bear.svg` and `mira.svg` are original front-view design drawings, with matching PNG exports. They establish faces and clothing but are not generated three-view turnarounds or evidence of hosted image quality. `harborlight-camp.svg` and its PNG export show the matching empty location: circular stone fire ring, timber bench behind it, and a path between two pine trees. They contain no character likenesses. The parent directory's tent/telescope style seed remains a separate treatment/style input and is not this scene's geometry reference.

Run `bun --no-env-file src/tools/prepare-harborlight-comic.ts` from the repository root to copy these inputs into a fresh isolated `runtime/examples/harborlight-comic` workspace and create valid character/location catalogs, register original cast drawings as `legacy-import` with `model: null`, and register original campsite art as `existing-canonical-art`. The helper registers the supplied campsite as `existing-canonical-art`, with its real checksum, rather than claiming provider generation. It refuses an existing destination. It creates no voice registrations, generated scene, panel images, QA labels, revision plan, audio, or slideshow.

Follow the [comic walkthrough](../../../../docs/commands/05-visuals/comic/00-comic-overview.md#walkthrough-harborlight) for local structure/prompt generation, the optional authored blocking-plan helper, hosted-stage prerequisites, cumulative estimates, and review. All edits and generated outputs belong in the copied runtime workspace. Leave this source bundle unchanged.

After genuine image generation and human review, `--publish-panels <image-run-id>` copies one complete single-model canonical individual-panel candidate run into the four canonical PNG names. It verifies all recorded hashes, full image decoding, dimensions, and destination nonexistence before writing; existing canonical images are preserved. It is a local publication bridge, not image generation or automated quality approval.
