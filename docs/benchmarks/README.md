# Benchmark Reports

This directory holds committed benchmark run data and the reports generated from it. The evidence lifecycle and paid-approval rules that governed these runs live in [ADR-015](../adr/ADR-015-govern-documentation-examples-and-verification-evidence.md). Pricing provenance, billing authority, and calibration promotion live in [ADR-010](../adr/ADR-010-hosted-model-registry-lifecycle-and-capability-policy.md).

## What this directory holds

- Per-modality run directories for `ocr`, `stt-local`, `stt-with-speakers`, `stt-without-speakers`, `url`, `tts`, `music`, `image`, `video`, and `write`, each keeping its retained per-run comparison reports and canonical result envelopes.
- The combined-report roots `ocr`, `stt-local`, `stt-with-speakers`, `stt-without-speakers`, and `url`. Each root holds `combined-comparison-report.json`, the data contract, and `combined-comparison-report.md`, the diffable text.
- One shared visual dashboard, `combined-comparison-dashboard.html`, with one tab per combined-report root.
- `summary.md`, a recomputed rankings summary built from the retained per-run comparison reports. Each provider/model identity keeps its original measured observations.

There is no CLI `benchmark` command. Reports are regenerated by the consensus skill from committed run data, and no runtime command, public flag, or execution API depends on this directory.

## Report architecture

The dashboard is generated from the same data as the per-root JSON and Markdown. It embeds its data and assets at generation time, opens directly from `file://` with no server, build step, network request, or third-party dependency, and renders its full content with JavaScript disabled. An optional on-page control can rescore one group for a reader's own quality, speed, and cost preference. That preference is a viewing aid only: it is not saved, and the emitted JSON and Markdown stay free of composites, overall scores, and model tiers.

Reports rank price, speed, and quality within each provider group. Local, non-diarization, diarization, and other category groups are never combined into a cross-group overall leaderboard. Combined reports regenerate whenever a run is added, so the dashboard is always generated, never hand-authored.

Earlier combined reports also assigned three contiguous quality-cost terciles per provider group under the method `quality-cost-terciles-v1`. That contract is retired: terciles were cohort-relative categories, not absolute quality labels, and live reports no longer emit tier membership or weighted composites.

## Compaction and regeneration

Compact a run only after trustworthy provider results exist. Preserve canonical result envelopes and historical identity, remove regenerable checkpoints, splits, and derived files only after validation, then regenerate the combined JSON and Markdown, then the dashboard, from those compacted artifacts. Finished artifacts keep the model identity they stored, and the cost recorded on a run remains the authority for that run.
