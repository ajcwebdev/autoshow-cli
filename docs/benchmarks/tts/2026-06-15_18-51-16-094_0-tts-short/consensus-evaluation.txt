PROVENANCE / METHOD
This evaluation is reconciled from measurable run evidence only:
  - manifest.json metadata (cost, processing time) and the consensus build-packet
    snapshot (audio duration, speaking rate).
  - voice-quality-report.json, generated in full mode (paidCallsAllowed=true):
    roundtrip intelligibility from AssemblyAI universal-3-pro STT (median
    roundtrip WER) and an auto-derived humanSpeechScore. The OpenAI gpt-audio
    naturalness judge ran (paidAudioJudgeRubric=scored).
No clip was listened to directly; all quality statements are attributed to the
voice-quality report and packet metadata. File size, bitrate, and duration are
not treated as quality.

SCOPE NOTE
All 15 providers in this run are third-party service models; there are no local
(zero-cost) TTS providers, so the local ranking surfaces are empty by design.
The 3-word input gives roundtrip WER very little to discriminate on — treat WER
here as a coarse intelligibility smoke check, not a graded accuracy ranking.

QUALITY COVERAGE CAVEAT
Offline naturalness MOS scorers (UTMOSv2, NISQA-TTS) were unavailable, so the
top-level naturalness aggregate is null and humanSpeechScore is driven by the
paid audio-judge rubric, prosody heuristics, signal hygiene, and roundtrip
intelligibility. Scores are directional for a smoke-test phrase, not a verdict.
