### Title

Miami Jam: A Game Show Format

### Description

Dev outlines Miami Jam, a show designed to break from typical interview or panel formats. Instead of straightforward questions, speakers face trivia about React, JavaScript quirks, libraries and each other's talks, using answers as segues into deeper discussion of their topics, motivations and industry experience, all in a more playful structure.
