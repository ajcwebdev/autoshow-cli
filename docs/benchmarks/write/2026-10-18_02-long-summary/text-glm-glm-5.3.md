## Episode Summary

This FS Jam episode departs from its usual guest format as the hosts explore the poorly documented world of building third-party JavaScript scripts and widgets. The Everfund founder shares lessons from creating a donation widget SDK, explaining how scripts must be bundled across module formats—CommonJS, ESM, and the oddly persistent UMD—to work reliably across browsers and platforms like WordPress, where a strange hosting conflict forced them to host the script locally. They weigh iframes versus direct DOM injection (CORS behavior, bundle size, CSS customization), the challenge of encapsulating styles on sites you don't control, and maintaining separate JavaScript and React SDKs. The conversation shifts to documentation philosophy (the Divio framework of tutorials, how-tos, reference, and explanation), then closes with podcast news: upcoming sponsors, more co-host episodes, the Remix conference, and how they vet guests while practicing responsible developer advocacy. The takeaway: shipping JavaScript that runs on other people's websites remains a puzzle with no established best practices, one learned only through painful firsthand experience.
