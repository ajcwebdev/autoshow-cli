## Episode Summary

In this co-host-only episode, the Everfund founder walks Anthony through the rarely documented craft of building a third-party JavaScript widget, using Everfund's donation script as a case study. He explains why injected scripts must typically be bundled to UMD since CommonJS fails on other sites, how Microbundle produced invalid UMD output so Rollup was added, and the tradeoffs of hosting scripts privately versus on npm CDNs. They weigh when it's safe to drop UMD for ESM given roughly 93% browser support, compare npm packages versus script tags for developer experience, and describe their separate JavaScript and React SDKs. Key challenges include CSS encapsulation, iframe versus DOM injection (iframes avoid CORS blocks and ease updates but resist styling customization), and a baffling WordPress bug solved by bundling the script inside the WordPress instance. Looking ahead, Everfund is building a headless donation SDK. The episode closes with podcast housekeeping: documentation approaches like Divio's taxonomy and ReadMe with Stripe as the benchmark, upcoming sponsorships, thoughts on vetting guests and sponsor trust, favorite recent episodes such as Hydrogen and Kent C. Dodds, and attending Remix Conference.
