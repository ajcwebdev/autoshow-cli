## Episode Summary

In this guest-free FSJam episode, the hosts explore the under-documented craft of building third-party embeddable scripts, drawing on one host's experience creating Everfund's donation widget. He explains the practical headaches: choosing between TypeScript and vanilla JavaScript, bundling to CommonJS, ESM, and the oddly persistent UMD format (which Microbundle couldn't produce correctly, forcing a separate Rollup step), deciding when to drop UMD given roughly 93% ESM browser support, and hosting via npm CDNs versus private S3 buckets. They weigh iframes against rendering directly into the host DOM, noting iframes avoid CORS issues and simplify updates but block customer CSS customization, and recount a baffling WordPress bug solved only by hosting the script inside the WordPress instance itself. Everfund is now evolving its SDK toward a headless donation system, and the host suggests a well-starred starter template may serve the community better than a startup. The conversation then shifts to writing good documentation using the Divio framework of tutorials, how-tos, explanations, and references, and to the podcast's future: introducing sponsors for sustainability, responsible developer advocacy, vetting guests, parasocial listener relationships, possible merchandise, and favorite recent episodes including Hydrogen, Flight Control, Blitz, Kent C. Dodds, Orta, and Miško.
