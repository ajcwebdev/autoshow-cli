## Episode Summary

In this loosely structured FS Jam episode, speaker-1 (a founder building the Everfund donation widget) and speaker-2 (Anthony, a developer advocate) explore the practical difficulties of writing third-party JavaScript scripts that run on other people's websites. They begin with the build pipeline, discussing why UMD remains the de facto format despite ESM being widely supported, noting that ESM reaches roughly 93% of browsers and that UMD bundles are larger because they target older syntax. The conversation then moves to distribution choices: privately hosted bundles versus npm and CDN delivery, and whether to ship a self-contained script or import an SDK into a framework. Integration strategy is a central theme, with the hosts comparing iframes, which avoid CORS issues and simplify updates but resist CSS customization, against injecting DOM directly. They also describe a WordPress-specific failure that was resolved by bundling the script inside the page. The episode then turns to documentation, where Anthony outlines the Divio categories of tutorials, explanations, references, and how-tos, and to podcast sustainability, including sponsorships, vetting guests, and the parasocial relationship with listeners. The hosts close by sharing favorite recent episodes and encouraging listener suggestions, with the overarching takeaway that browser script delivery is a hard problem without a settled best practice.
