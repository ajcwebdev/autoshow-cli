## Episode Summary

In this FS Jam episode, the hosts unpack the rarely documented craft of building third-party JavaScript widgets that must run reliably on other people's websites. Drawing on Everfund's donation widget, they explain why UMD remains the practical bundle format even though it has barely changed since 2017, how CommonJS fails when injected through a script loader, and why ESM's roughly 93 percent browser support still leaves a painful gap for products that must work every time. They compare distribution paths—npm packages, CDNs, raw script tags, and a WordPress plugin that only worked after the script was hosted inside the site—and weigh iframe widgets, which avoid CORS and let the vendor update the UI without republishing the loader, against DOM injection, which allows CSS customization but is harder to encapsulate. The talk then widens to vanilla and React SDKs, documentation systems such as Divio's split of tutorials, explanations, references, and how-tos, and Everfund's move to ReadMe. They close by discussing sponsorships, responsible advocacy, listener relationships, and recent favorite episodes on Hydrogen, Flight Control, Blitz, Kent C. Dodds, and Orta.
