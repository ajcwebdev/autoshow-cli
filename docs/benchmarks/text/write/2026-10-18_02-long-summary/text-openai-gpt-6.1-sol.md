## Episode Summary

The FSJam hosts explore the challenges of building third-party JavaScript widgets through Everfund’s donation SDK. They compare UMD, CommonJS, and ES modules, weighing browser compatibility against bundle size, and discuss CDN hosting, npm packages, framework integration, and a WordPress issue solved by hosting the script locally. The conversation then contrasts iframe-based widgets with direct DOM rendering: iframes simplify isolation and updates but limit styling customization. Everfund’s planned headless donation API illustrates a shift toward giving developers control over their own interfaces. From there, the hosts discuss documentation, distinguishing tutorials, how-to guides, explanations, and API references. They close by considering FSJam’s future, including more host-only discussions, sponsorships, and merchandise to support production. Throughout, they emphasize education-first advocacy, vetting guests and sponsors, and preserving listener trust, while framing the podcast as a lasting record of web development’s evolving ideas.
