## Episode Summary

This FS Jam episode is a host-only conversation exploring the poorly documented work of building third-party JavaScript widgets that must run on other people's websites. Drawing on Everfund's donation widget, the hosts discuss choosing TypeScript versus vanilla JS, bundling with Microbundle and Rollup, and why UMD remains necessary for script-tag loaders even as ESM coverage sits around 93 percent. They compare npm packages and CDN-hosted scripts, React SDKs versus a small core JS class, iframes versus injecting into the host DOM, CORS, CSS encapsulation, and a WordPress edge case that forced hosting the script inside the plugin. The conversation then turns to documentation (tutorials, how-tos, explanation, and reference), Remix Conf in Utah, responsible advocacy versus pitches, first-time sponsorships to make editing sustainable, merch, and recent favorite episodes such as Hydrogen, Flight Control, Kent C. Dodds, and Orta. They finish by treating the show as a historical record of web platform choices and inviting listeners to suggest topics while they continue to vet guests.
