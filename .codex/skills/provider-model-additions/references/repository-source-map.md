# autoshow-cli Repository Source Map

Use this checkout's runtime and CLI as the implementation baseline. Derive all inventory counts, defaults, service keys, and implementation status from the current autoshow-cli snapshot; do not carry them over from autoshow-bun reports.

The eight research workflows are `write`, `ocr`, `url`, `stt`, `image`, `video`, `music`, and `tts`. The CLI exposes writing through `write`, OCR/URL/STT through `extract`, and generation through `image`, `video`, `music`, and `tts`. Workflow labels, model-registry keys, CLI provider selectors, and adapter service keys are distinct; record their mapping rather than assuming they match.

Start with these repository sources, then follow their imports to the executing request and response code:

- **Shared model configuration:** `src/cli/commands/setup-and-utilities/models/`. `model-loader/registry.ts` loads the `llm`, `extract`, `stt`, `image`, `video`, `music`, and `tts` registries. Inspect `model-loader/paths.ts`, `model-loader/model-config-loader.ts`, and `model-loader/model-loader-schemas.ts` for config layout and validation. The `ocr-config/`, `stt-config/`, and `tts-config/` directories contain per-service JSON fragments; the other registries use `llm-config.json`, `image-config.json`, `video-config.json`, and `music-config.json`.
- **Selection, defaults and lifecycle:** The workflow `*-models.ts` files validate public selectors, and `supported-model-sources.ts` connects their arrays to registry services and `MODEL_SELECTOR_FREE_SERVICES`. `cheapest-models.ts` resolves bare-provider/omitted-provider defaults; `video-cheapest-candidates.ts` can choose a complete mode/duration/resolution candidate. Execute these resolvers read-only when recording defaults. `model-loader/defaults.ts` holds cost/timing constants, not the selection algorithm. `model-loader/model-lifecycle.ts` resolves lifecycle/default/all-expansion eligibility for the registries that carry it; extract entries also restrict shortcuts independently. `model-loader/retired-model-rates.ts` holds historical accounting and migration context, not selectable models.
- **Text/write:** `llm-config.json` and `llm-models.ts` under the model configuration directory; dispatch and adapters under `src/cli/commands/text/write/`, including `run-llm.ts` and `write-services/`.
- **OCR:** `ocr-config/` and `ocr-models.ts` under the model configuration directory. `src/cli/commands/text/ocr/hosted-ocr-adapters.ts` selects and invokes adapters under `ocr-services/`; `ocr-engine-selection.ts` resolves active engines. `ocr-utils/hosted-ocr-lane-registry.ts` schedules concurrency only. Local Tesseract runs through `ocr-utils/tesseract-utils.ts` and has no model-registry record; inventory it separately with no upstream model. Native format extraction is not another OCR model tuple.
- **URL:** The URL entries in the shared `extract` registry, plus `src/cli/commands/text/url/url-provider-registry.ts`, `url-targets.ts`, `url-local/`, and `url-services/`. The `ocr-config/` directory also contains web-page extraction services; classify these as URL entries instead of counting them again as OCR. Include services with no selectable model and preserve any internal registry ID without presenting it as a provider model release.
- **STT:** `stt-config/` and `stt-models.ts` under the model configuration directory; `src/cli/commands/stt/stt-targets.ts` resolves source-eligible targets, `stt-cli.ts` maps public/provider names, and `run-stt/dispatch.ts` executes adapters. Transcript/caption retrieval belongs in STT even when its adapter lives under `src/cli/commands/text/url/url-services/`. `--youtube-captions` has no provider selector: `process-stt.ts` routes its caption completion before ordinary STT dispatch, and its registry ID describes a subtitle track rather than a released model.
- **Image:** `image-config.json` and `image-models.ts` under the model configuration directory; `src/cli/commands/visuals/image/image-generation-targets/image-provider-registry.ts` and adapters under `src/cli/commands/visuals/image/image-generation-services/`.
- **Video:** `video-config.json` and `video-models.ts` under the model configuration directory; `src/cli/commands/visuals/video/video-targets/video-provider-registry.ts` and adapters under `src/cli/commands/visuals/video/video-services/`.
- **Music:** `music-config.json` and `music-models.ts` under the model configuration directory; `src/cli/commands/audio/music/music-targets/music-provider-registry.ts` and adapters under `src/cli/commands/audio/music/music-services/`.
- **TTS:** `tts-config/` and `tts-models.ts` under the model configuration directory; target collection in `src/cli/commands/audio/tts/tts-targets/tts-target-collect.ts`, serializers under `script-to-audio/`, and adapters under `tts-services/` in the same TTS directory. Keep endpoint, spoken text, inline delivery tags, and request-level instructions distinct when assessing capabilities.
- **CLI routing and provider names:** `src/cli/command-definitions.ts` owns command names. `src/cli/flags/service-selector-normalization/provider-targets.ts`, `extract-selectors.ts` and `generic-provider-selectors.ts` map public provider selectors by command/input. Extract definitions live in `src/cli/commands/command-shared/extract-routing/provider-registry/{stt-providers,ocr-providers,url-providers,entries,provider-registry-selection}.ts`; the neighboring `provider-registry.ts` is their export barrel. Generation selection is owned by `src/cli/commands/command-shared/generation-routing/generation-selection-entries.ts` and model facts/expansions by `generation-model-registry.ts`. Repository-wide credential names live in `src/cli/commands/setup-and-utilities/setup/hosted-provider-config.ts`; credentials are not a workflow-support inventory.
- **Rates and actual consumers:** `model-loader/{stt,extract,llm-accessors,tts,image,video,music}.ts` exposes stored rates. Follow each into `src/cli/commands/pricing-orchestration/compute-estimated-costs/`, `aggregate-pricing/` and `src/utils/pricing/`, plus workflow estimators such as `src/cli/commands/audio/tts/tts-utils/tts-pricing.ts`. Trace units, rounding, minimums and actual-usage authority instead of comparing rate numbers alone.
- **Verification and prior evidence:** `package.json`, `test/test-runner/runner.ts`, `price-execution.ts` and `price-commands/registry/` own the mapped price commands; test directory names alone do not establish pricing coverage. Existing `supported-model-source-contracts.test.ts` checks bidirectional registry/selector parity. `test/test-cases/validation/providers/provider-research-source-map.test.ts` exercises actual default resolution, model-free/local exceptions, hosted dispatch descriptors and routed mapped-price selections. Consult existing report owners, ADRs and benchmark artifacts for dated context; their model lists and results do not override executing code.

Reconcile records with actual selection and dispatch. URL article services (`defuddle`, `spider`, `zyte`) share the `extract` registry with OCR, so classify them through their URL entries/adapters rather than by directory name. A local backend can lack a registry record (Tesseract) or carry an internal operation ID with no upstream model selector (Defuddle). `gemini` and `openai` public STT selectors map to `gemini-stt` and `openai-stt` registry/adapter services. Explain these distinctions without inflating counts with aliases, retired rates/types/stubs, empty directories or one backend reached by multiple commands. Higher-level consumers such as comic and resume add no tuples unless they select a distinct workflow/service/model combination; voice provisioning, local alignment, native format extraction and X Spaces acquisition are outside the eight-workflow model inventory.

For TTS, follow `tts-utils/tts-pricing.ts`, provider-specific pricing modules and the model loader's `tts.ts` to distinguish published units from estimated units. Inspect `script-to-audio/provider-serializer-registry.ts`, `tts-targets/multi-speaker-capability.ts` and `src/cli/commands/audio/voice/` before recommending controls, native dialogue or voice provisioning that may already exist. Record wire-ID/default translation and endpoint-specific input fields. Use ADR-010 for lifecycle/eligibility, ADR-012 for voices and retained audio, ADR-015 for evidence/verification and `AGENTS.md` for current paid execution, episode-publishing and privacy rules.

Use repository-relative paths in report data and relative Markdown links from each report. Keep reports under `docs/reports/` and preserve established benchmark locations. Any necessary maintenance helper belongs under `src/tools/`, and test harnesses belong under `test/`; do not create Python files, a root-level `scripts/` directory, or any new root-level directory.
